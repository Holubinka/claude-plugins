Use the `spec-creator` agent to write a specification for a "saved views" feature.

The goals are:

1. A customer can save the current filter set under a name and return to it later.
2. A saved view can be shared with a teammate by link.
3. The list of saved views loads fast enough not to delay the page.

Nothing else has been decided yet — goal 3 in particular has never been given a number.
